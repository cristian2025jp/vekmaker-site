FAQ

What is a box divider insert?

It is a removable grid that fits inside an existing open box. It adds compartments without generating a new box or a new bottom.

How is this different from the Divider Box Generator?

The Divider Box Generator creates the box and its compartments together. This tool creates only the removable divider structure for a box you already have.

What clearance should I use?

For a 3D printed box, 0.5 mm per side is a useful starting point. Increase it if the box has dimensional variation or if you want the insert to come out more easily.

Does the insert have a bottom?

No. The insert is only the perimeter and divider grid, so the existing box bottom remains the bottom of every compartment.

How should it be printed?

Print it upright with the full divider grid touching the build plate. The model is a single continuous mesh and normally requires no supports.
