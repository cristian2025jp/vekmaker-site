About VEKMaker

Simple tools for creating printable models

VEKMaker helps makers create customizable STL files directly in the browser.

What is VEKMaker?

VEKMaker is a collection of browser-based tools for creating customizable STL files for 3D printing. Each generator is designed to make common models easier to create without requiring CAD software or an installation.

How it works

Choose a generator, enter the dimensions or options you need, preview the model and download the STL file. The model is generated directly in your browser, so your design parameters do not need to be uploaded to VEKMaker.

Our goal

The goal of VEKMaker is to provide practical, accessible and easy-to-use tools for makers, hobbyists and small businesses. New generators and improvements will be added over time.
