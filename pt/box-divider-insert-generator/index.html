Perguntas frequentes

O que é uma divisória removível para caixa?

É uma grade divisora removível que entra em uma caixa aberta já existente. Ela cria compartimentos sem gerar uma nova caixa e sem adicionar outro fundo.

Qual é a diferença para o Divider Box Generator?

O Divider Box Generator cria a própria caixa junto com os compartimentos. Este gerador cria somente a divisória removível para uma caixa que você já possui.

Qual folga de encaixe devo usar?

Para uma caixa impressa em 3D, 0,5 mm por lado é um bom ponto de partida. Aumente se a caixa tiver variações nas medidas ou se quiser retirar a divisória com mais facilidade.

A divisória possui fundo?

Não. A peça contém apenas o contorno e a grade de divisórias. O fundo da própria caixa continua sendo o fundo de todos os compartimentos.

Como devo imprimir?

Imprima em pé, com toda a grade de divisórias apoiada na mesa. O modelo é uma única malha contínua e normalmente não precisa de suportes.
