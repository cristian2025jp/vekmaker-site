Perguntas frequentes

Como funciona esta caixa?

Ela usa duas peças para impressão: uma capa externa e uma gaveta interna que desliza para dentro e para fora como uma caixa de fósforo.

Preciso ajustar espessura da parede ou folga de deslizamento?

Não. Este gerador simplificado utiliza valores internos fixos, então você escolhe apenas o tamanho útil e algumas opções visuais.

Para que serve o recorte para o dedo?

O recorte opcional facilita puxar a gaveta interna para fora da capa.

O que faz a opção de divisória?

A opção de 2 compartimentos adiciona uma divisória central na gaveta interna.

Como as peças devem ser impressas?

A gaveta foi projetada para imprimir em pé sobre o fundo. A capa externa é exportada apoiada em uma das extremidades abertas para reduzir a necessidade de suportes.
