Apoie o VEKMaker

Ajude a manter o VEKMaker gratuito

O VEKMaker é gratuito. Se as ferramentas foram úteis para você, é possível apoiar o desenvolvimento contínuo com uma contribuição voluntária.

Por que apoiar o VEKMaker?

O VEKMaker é desenvolvido como uma coleção gratuita de ferramentas no navegador para criar arquivos STL personalizáveis. O apoio ajuda no tempo e nos recursos necessários para manter o site, melhorar os geradores existentes e criar novas ferramentas.

Uma pequena contribuição já ajuda

Nenhum pagamento é necessário para usar os geradores. Apoiar o projeto é totalmente opcional e é apenas uma forma de ajudar o VEKMaker a continuar crescendo.

Apoie o projeto ☕

Você pode fazer uma contribuição voluntária pelo Buy Me a Coffee.

Apoiar o VEKMaker no Buy Me a Coffee

Você será direcionado ao Buy Me a Coffee. As contribuições são opcionais e não liberam recursos adicionais no VEKMaker.
