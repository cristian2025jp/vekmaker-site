Sobre o VEKMaker

Ferramentas simples para criar modelos imprimíveis

O VEKMaker ajuda makers a criar arquivos STL personalizáveis diretamente no navegador.

O que é o VEKMaker?

O VEKMaker é uma coleção de ferramentas que funcionam no navegador para criar arquivos STL personalizáveis para impressão 3D. Cada gerador foi desenvolvido para facilitar a criação de modelos comuns sem exigir software CAD ou instalação.

Como funciona

Escolha um gerador, informe as dimensões ou opções necessárias, visualize o modelo e baixe o arquivo STL. O modelo é gerado diretamente no seu navegador, portanto os parâmetros do seu projeto não precisam ser enviados ao VEKMaker.

Nosso objetivo

O objetivo do VEKMaker é oferecer ferramentas práticas, acessíveis e fáceis de usar para makers, hobbistas e pequenos negócios. Novos geradores e melhorias serão adicionados ao longo do tempo.

Feedback e sugestões

Ideias para novos geradores e relatos de problemas são bem-vindos. Acesse a página de Contato para falar conosco.
